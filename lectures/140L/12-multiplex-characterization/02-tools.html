Next-Gen Sequencing (NGS)

Illumina

  • Illumina NovaSeq X (25B flow cell):
  • 52-70 billion paired-end reads per run
  • run time ~48 hours at 2 x 150 bp
  • Illumina MiSeq i100 (25M flow cell):
  • 50 million paired-end reads per run
  • run time 4-24 hours
  • Reagents run ~$1,100 a flow cell on the MiSeq to ~$2,600 on the NovaSeq X
