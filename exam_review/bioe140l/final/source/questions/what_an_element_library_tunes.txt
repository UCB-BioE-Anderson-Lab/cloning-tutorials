slug: spread_is_the_product_not_a_defect
difficulty: easy
topic: Interpreting the spread a library produces
question: |
  You pick twenty clones from a ribosome binding site library and find reporter levels spanning about fortyfold. How should you read that spread?
choices:
  A: As contamination, since one construct gives one level
  B: As the intended result, since the library varies initiation
  C: As evidence the ligation included empty vector
  D: As clone-to-clone noise that averaging will remove
  E: As a sign the reporter is unstable in this host
answer: B
explanation: |
  Changing the ribosome binding site changes how efficiently ribosomes initiate on the message, so a range of protein levels is what the library was built to produce. Treating the spread as a defect to be cleaned up discards the whole point. The spread is far too large and too reproducible per clone to be measurement noise, and empty vector or an unstable reporter would show up as a loss of signal rather than as a graded series.

slug: promoter_versus_rbs_step
difficulty: easy
topic: Matching an element to the step it controls
question: |
  A promoter library and a ribosome binding site library both change protein output. Which step does each one act on?
choices:
  A: Both on transcription, differing only in magnitude
  B: Promoter on translation; RBS on message stability
  C: Both on translation, since protein is the readout
  D: Promoter on copy number; RBS on transcription
  E: Promoter on transcription; RBS on translation initiation
answer: E
explanation: |
  The promoter sets how often polymerase initiates, so a promoter library varies the amount of message, while the ribosome binding site sets how readily the ribosome loads onto that message, so an RBS library varies protein made per message. Both end up changing protein, which is what makes the shared readout tempting, but the question is which step is being varied. The other options swap the two assignments or substitute copy number.

slug: tuning_a_ratio_within_an_operon
difficulty: medium
topic: Choosing which element to vary for a stated goal
question: |
  Two enzymes are expressed from one operon behind a single promoter, and you need more of the first and less of the second. Which change does that?
choices:
  A: Replace the promoter with a stronger one
  B: Move the operon to a higher copy number origin
  C: Vary the ribosome binding site of the second gene
  D: Add a second promoter copy upstream of the operon
  E: Change the codon usage of both genes together
answer: C
explanation: |
  Everything upstream of the operon acts on both genes at once, so a stronger promoter, an extra promoter, or a higher copy number raises both and leaves the ratio where it was. The ribosome binding site sits in front of one coding sequence and sets translation of that one, which makes it the only element here that can move the two independently. Recoding acts on both genes and is a blunt instrument for level in any case.

slug: terminator_library_readout
difficulty: medium
topic: Identifying the measured quantity for a terminator library
question: |
  A terminator library sits between an upstream and a downstream fluorescent reporter. What does the construct measure for each member?
choices:
  A: The absolute brightness of the upstream reporter
  B: The plasmid copy number of each individual clone
  C: The folding rate of the upstream reporter protein
  D: The downstream to upstream ratio, that is read-through
  E: The translation initiation rate of the downstream gene
answer: D
explanation: |
  A terminator is judged by how much transcription it stops, and the way to see that without being confused by clone-to-clone differences in copy number or growth is to put a reporter on each side and take a ratio. The upstream reporter is the internal reference and the downstream one reports read-through. Absolute brightness would vary with copy number and growth rather than with the terminator, and the remaining options name quantities the construct does not isolate.

slug: rbs_library_with_no_effect
difficulty: medium
topic: Interpreting a library that produces no spread
question: |
  An RBS library in front of a pathway enzyme gives the same pathway output for every clone. What is the most plausible explanation?
choices:
  A: That enzyme is not the step limiting pathway output
  B: The library has no diversity, since output is identical
  C: The promoter was deleted during the cloning
  D: Cytometry rather than a plate reader is required
  E: The ribosome binding site does not act in E. coli
answer: A
explanation: |
  The library almost certainly produced a range of enzyme levels; what the experiment shows is that pathway output does not respond to that range, which is what it looks like when some other step is the bottleneck. Sequencing is worth doing but identical output has an easier explanation than identical sequence, a deleted promoter would abolish output rather than fix it at one level, and changing the instrument changes nothing for a bulk pathway measurement.

slug: copy_number_versus_element_strength
difficulty: medium
topic: Separating dosage from element strength
question: |
  Moving a reporter from a p15A origin to a high-copy origin raises the signal fourfold, and a colleague concludes the promoter is stronger. What is wrong?
choices:
  A: Copy number multiplies templates, leaving initiation rate alone
  B: Nothing, as strength and copy number are one quantity
  C: High-copy origins silence promoters, so signal should fall
  D: Fluorescence cannot be compared between two strains
  E: The promoter is weaker, as output is spread over more templates
answer: A
explanation: |
  Promoter strength is a property of one template: how often polymerase initiates there. Raising copy number gives more templates, each initiating at the same rate, so total output rises while the promoter is untouched. This is the distinction every expression comparison depends on. Silencing is invented, the comparison is routine given proper normalization, and the last option confuses total with per-template while drawing the opposite wrong conclusion.

slug: library_is_a_distribution_not_an_answer
difficulty: hard
topic: Treating a library as a distribution to be sampled
question: |
  A colleague says the purpose of an RBS library is to find the strongest ribosome binding site. What is the better description?
choices:
  A: A single optimum, which sequencing the pool reveals
  B: A measure of the maximum expression the host sustains
  C: A set of clones at one level, differing only in sequence
  D: A distribution, from which the screen picks the level needed
  E: A prediction of level from sequence, needing no measurement
answer: D
explanation: |
  The library is a population spanning a range, and what counts as the best member depends on the goal: a pathway enzyme may need a middling level and a toxic product a weak one. Treating the library as a search for a maximum discards most of its value. Sequencing the pool tells you what is there rather than what works, the host maximum is a different experiment, uniform levels contradict the method, and a predictive model is what libraries are used to build rather than to replace.

slug: toxic_product_distorts_a_recovered_library
difficulty: hard
topic: Recognizing survivor bias in a recovered library
question: |
  You transform an RBS library in front of a gene whose product is toxic above some level, then grow overnight before picking. How does the recovered library differ from the design?
choices:
  A: Unchanged, since toxicity affects rate rather than survival
  B: Depleted of the weakest members, which are outcompeted
  C: Unchanged in composition but lower in copy number
  D: Enriched for the strongest, which gain an advantage
  E: Depleted of the strongest, which grow poorly or not at all
answer: E
explanation: |
  Overnight outgrowth is a selection whether or not you intended one. Clones expressing the toxic product most strongly divide slowly or die, so the high end of the designed distribution is thinned out or missing from what you pick. This is the same logic as plasmid loss under antibiotic: the population you measure is the population that survived the measurement. A growth-rate difference over many generations does become a composition difference, and the other options have the direction backwards or invent an unrelated effect.

slug: why_an_rbs_library_rather_than_codon_changes
difficulty: medium
topic: Choosing a tuning handle with a predictable effect
question: |
  Why is an RBS library a better handle on one enzyme's level than recoding the gene with synonymous codons?
choices:
  A: Codon changes cannot alter protein level at all
  B: A short separable element spans a wide range untouched protein
  C: Codon changes need chip synthesis, unavailable at this size
  D: The ribosome binding site determines how the protein folds
  E: Synonymous changes alter the amino acid sequence
answer: B
explanation: |
  Varying a short element upstream of the start codon gives a broad and roughly monotonic range of initiation rates while leaving the coding sequence alone, which keeps the enzyme itself out of the comparison. Recoding does shift expression, but through several entangled mechanisms including message structure and elongation, and across the whole gene. Synonymous changes by definition do not change the protein, and folding is not set by the ribosome binding site.

slug: holding_the_context_constant_in_a_part_library
difficulty: hard
topic: Controlling the context around a varied part
question: |
  Each candidate terminator is cloned into the same position in the same reporter plasmid rather than tested in the vector it arrived in. Why does that matter?
choices:
  A: It raises the theoretical diversity of the library
  B: It is required for the parts to be cycle sequenced
  C: It raises the copy number and so the signal
  D: It removes the need for an upstream reference reporter
  E: It holds everything but the part under test identical
answer: E
explanation: |
  A part's measured behavior depends on its surroundings: promoter, copy number, growth, and the reporters on either side. Putting every candidate into one fixed context makes the measurements comparable with each other, which is the premise of characterizing parts at all. Diversity and sequencing are unrelated, any copy number change is incidental rather than the reason, and the internal reference is still needed to handle clone-to-clone variation.
