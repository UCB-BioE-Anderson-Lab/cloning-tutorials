slug: multichannel_alignment_requirement
difficulty: medium
topic: Plate layout constraints for multichannel pipetting
question: |
  A robot has an 8-channel pipette head and needs to transfer the same reagent into eight wells at once. Which sample layout best supports efficient multichannel pipetting?
choices:
  A: Samples placed in any open wells without regard for plate position.
  B: Samples aligned in one row or one column of a plate.
  C: Samples distributed across different plates and separate reservoirs.
  D: Samples placed along a diagonal from well A1 through well H8.
answer: B
explanation: |
  Multichannel pipettes work efficiently when wells line up with the fixed spacing of the channels, usually along a row or column. Random, diagonal, or scattered layouts force slower single-channel transfers or waste channels and tips. This is a physical constraint of the pipette geometry, not a biological constraint.

slug: mastermix_advantage
difficulty: easy
topic: Why mastermixes improve liquid-handling workflows
question: |
  You are setting up many PCRs that share water, buffer, dNTPs, polymerase, and the same primer pair, but differ by DNA template. Why prepare a mastermix?
choices:
  A: It lets the robot skip template addition entirely.
  B: It replaces the need for a thermocycler program.
  C: It reduces shared-reagent transfers and improves consistency.
  D: It converts the PCR reactions into sequencing reactions.
answer: C
explanation: |
  A mastermix combines reagents that are common across reactions, so they can be distributed as one mixture. This reduces pipetting steps, saves tips, saves time, and makes shared reagent concentrations more uniform. Templates still need to be added separately, and the PCR still needs a thermocycler program.

slug: tip_reuse_cross_contamination
difficulty: medium
topic: Tip reuse and contamination constraints
question: |
  A robot distributes the same mastermix from one reservoir into 96 empty PCR wells. It then adds a different DNA template to each well. Which tip strategy is most reasonable?
choices:
  A: Use one tip for mastermix distribution and fresh tips for each template.
  B: Reuse a single tip for every template transfer to reduce tip cost.
  C: Use fresh tips for mastermix distribution and reuse tips for templates.
  D: Skip tips for mastermix entirely because the source reagent is shared.
answer: A
explanation: |
  Reusing one tip to distribute a shared mastermix from the same source into empty wells can be reasonable if there is no back-contamination risk. Different DNA templates should use fresh tips to avoid cross-contamination between samples. B and C would risk mixing templates, and D is physically impossible for ordinary pipetting.

slug: hard_mastermix_tip_count
difficulty: hard
topic: Reasoning about transfers, templates, and tip counts
question: |
  A robot sets up 96 PCRs. Each reaction gets the same commercial PCR mix, the same forward primer, and the same reverse primer, but a unique DNA template. The robot prepares one mastermix from those three shared components, distributes it to all wells, and then adds templates. Assume one tip can be reused while distributing the shared mastermix, but template transfers require fresh tips.

  What is the best estimate of the total number of tips used for these steps?
choices:
  A: 97 tips: one shared transfer tip and 96 template tips.
  B: 99 tips: three setup tips and 96 template tips.
  C: 100 tips: three setup tips, one distribution tip, and 96 template tips.
  D: 192 tips: one mastermix tip and one template tip for each PCR.
answer: C
explanation: |
  Preparing the mastermix uses one tip for each of the three shared components. Distributing the mixed reagent to the plate can use one additional tip if the same mixture is dispensed into empty wells. Adding 96 distinct templates requires 96 fresh tips. The total is 3 + 1 + 96 = 100. The other answers omit either setup tips or distribution logic, or double-count the shared mastermix distribution.
