Protocol

  1. Fill the plate. P200 multichannel, 100 µL per well into a black-walled, clear-bottom 96-well plate. Each culture 2×. Skip any culture that did not grow.
    • Tips all seated, pipette up and down to resuspend, no air gaps. Volume sets the signal — pipette accurately.
  2. Start up, in this order, from everything off: the computer (PIN from a supervisor), then the instrument (toggle on the back), then iControl.
  3. Connect: choose Infinite 200 Pro, OK. It always takes a while.
    • Will not connect? End iControl (Task Manager if it hangs), switch everything off, and start again in the same order.
  4. Default script. Select only the wells you filled.
  5. Add Absorbance: 600 nm. Add Fluorescence Intensity: ex 483 nm, em 525 nm, gain 40. Leave everything else at its default.
  6. Open the tray (iControl or the corner button). Plate in the slot, A1 top left. Close the same way. Never push or pull the door by hand.
  7. Start. Results open in Excel, absorbance and fluorescence on separate sheets. File → Save As to the desktop with a real name, then USB stick or email.
  8. Plate out first, close the tray. Quit Excel; quit iControl — yes disconnect, no save script. Shut down the computer, then the instrument.
  9. Bleach and rinse the plate.

Reads OVER? Out of range — lower the gain and read again. Numbers weak — raise it.
