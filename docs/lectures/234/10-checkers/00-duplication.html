Biology as a predicate · BioE 134/234

Start with a test that fails

…aatatcagGGTCTCatacagtagc…

Your designer emitted this. Your test looks for BsaI. It fails.

There is only one way it ever passes

  • The algorithm has to know about GGTCTC too
  • Otherwise it stays blissfully unaware it is making the error
  • So now the same rule is written down in two places
  • And they only agree until one of them is edited

So take the rule out of both

One function. “Is there a BsaI site in this?”

The algorithm calls it to choose. The test calls it to judge. There is one definition of the rule, so there is nothing to drift.

And now the rule itself can be tested, which it could not be when it was spread across two files.
