Where the threshold comes from

The code is not the hard part

def run(self, seq: str) -> bool:
    return max(self._score(seq, i) for i in range(len(seq) - 5)) < CUTOFF

Any model writes that in about four seconds.

None of them can tell you what CUTOFF should be.

What makes a number defensible

A source — somebody measured this, and you can say who and where
A calibration set — sequences whose answer you already know, independently
A consequence you can see — move the number, and watch what changes

A threshold with none of these is a guess wearing a lab coat. It will be wrong, and worse, nothing in your code will ever tell you.

Where would you put it?

An internal σ70 promoter inside your coding sequence would transcribe antisense RNA and knock your own gene down.

You score the sequence against a position weight matrix. The maximum possible score is 16.5.

Pick a cutoff. Defend it.
