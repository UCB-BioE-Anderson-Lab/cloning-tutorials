Recombinases

One protein cuts, swaps and reseals all four strands — no ligase, no polymerase, no free ends

  • Site-specific: Cre/lox, Flp/FRT, phage integrases
  • Homologous: recombineering, RecA

Cre Recombinase: the Arrow Decides

Cre in Practice

  • “Floxing” a gene — build it into the genome flanked by loxP, then supply Cre later and it is deleted on cue
  • Excision is effectively one-way: the circle carries no origin, and putting it back is a two-molecule reaction — it dilutes away
  • Inversion is freely reversible: same sites, same enzyme, it keeps flipping. On its own it will not latch, so it is a poor memory element
  • Flp/FRT (yeast 2µ plasmid) is the same trick on a different 34 bp site
  • Every reaction leaves one site behind — run the same recombinase again and it will find that scar

Phage att Sites

  • The lox-like sites are called att sites; the Cre-like enzymes are Int recombinases, or integrases
  • λ Int joins attP (phage) to attB (host) — the products are attL and attR, which are new sequences
  • Int + host IHF integrates; Int + Xis + IHF runs it backwards, so λ is a switch, not a ratchet
  • This is Gateway cloning: BP clonase (Int) makes the Entry clone, LR clonase (Int + Xis) makes the Expression clone
  • Also phi80, HK022, P21, P22, phiC31

Serine Integrases: a One-Way Reaction

Homologous Recombination

  • Yeast and B. subtilis readily catalyze homologous recombination
  • E. coli requires additional genes for it to be efficient
  • The lambda Red genes (from lambda phage) are one such set of genes
  • Used for “recombineering” — recombination-based manipulation of the genome or plasmids in E. coli
  • Often used for knocking out genes in E. coli
  • Endogenous RecA protein is also involved in the reaction
  • RecA is a protein involved in DNA repair pathways that stabilizes single-stranded DNAs
  • RecA can also be used to promote homologous recombination in vitro
