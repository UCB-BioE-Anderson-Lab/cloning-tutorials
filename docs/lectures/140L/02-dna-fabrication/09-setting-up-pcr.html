PCR Protocol (printed out in lab)

Set up a PrimeSTAR PCR (2-40 kb)

Set up the following reaction in a PCR tube, in the following order:

32 uL ddH20
10 uL 5X PrimeSTAR GXL Buffer
4 uL dNTP Mixture (2.5 mM each)
1 uL 10uM primer 1
1 uL 10uM primer 2
1 uL dil20x plasmid template
1 uL PrimeSTAR GXL DNA Polymerase
  1. Slam on the benchtop to mix thoroughly
  2. Give a quick spin to knock all the liquid to the bottom of the tube
  3. Run the appropriate PCR program from your worksheet
