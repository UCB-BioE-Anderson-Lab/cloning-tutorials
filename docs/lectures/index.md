# Lectures

Slide decks from the Anderson lab's Berkeley bioengineering courses, built to
run in a browser rather than in PowerPoint.

Each deck is a set of linked pages. The arrow keys advance one step at a time —
a click on the slide deliberately does nothing, so a stray tap on a projector
cannot lose your place. **G** jumps between sections, **P** opens presenter view
with the narration beside the slide, **W** shows the two text channels, and **?**
lists every key. Use **F11** (**⌃⌘F** on a Mac) for full screen: it is the one
that survives moving between sections.

The figures are not pictures of animations. They are drawn live, so a mechanism
can be stepped through at whatever pace the room needs, and every step has
narration written for it.
